QRun Blockchain: Current Technical Status

Updated 20 November 2026. This page distinguishes integrated source code and successful scoped tests from a live public network, spendable native balances, or a production release. A successful local or hosted test is not proof of public-Internet operation.

Current release boundary: the QFP6 Unified candidate has integrated the native runtime, wallet tooling, peer/recovery components, market-operation modules and Q6GA v2 zero-value Testnet authorization inputs. The public zero-value Testnet is not launched. Mainnet, real-value transfers, public mining rewards and native-market activity remain unauthorized.

Public Testnet and Seed status

The owner-signed Q6GA v2 authorization is scoped to ZERO_VALUE_PUBLIC_TESTNET_ONLY. It does not authorize Mainnet, real-value transfers, public mining rewards, or market operations.

The release candidate still lacks a qualified public bootstrap set and an attested, stable Seed endpoint bound to the exact release package. The current package validator therefore remains INCOMPLETE. The active Seed endpoint has not been demonstrated as reachable from independent public networks, and no independently operated Joining node has been shown to complete full-history synchronization against this release package.

Prior private-overlay and loopback tests remain useful evidence for those specific environments; they are not public Internet ingress qualification. The project is not advertising a live public multi-operator network.

Wallet, RPC and explorer

  • Native wallet: a candidate QRun wallet binary is built, and Windows DPAPI / QZKW2 / Q6HA signing regressions have passed in hosted validation. This is not a public wallet service and no native QZXB transfer or spendable Mainnet balance is confirmed.
  • Read API: canonical status, account, supply, block and transaction read paths exist in the candidate. The listener is disabled by default; public access has not been enabled. Account inclusion proofs and an independently verified full-node state replay are not yet provided by the current public service.
  • Explorer and indexer: a production-ready native block explorer, public indexer and monitored public RPC service are not yet established.

Native market and economics

The active candidate monetary policy is CP-0651: a 7,000,000,000 QZXB maximum gross accounting ceiling, comprising a 1,000,000,000 QZXB owner Genesis allocation and six additional 1B non-circulating accounting labels. The labels are not issued balances or mint authority. Block subsidy is zero; candidate producers receive canonical transaction fees only.

Q6MO/Q6MA signed market-operation ingress, Q6MM durable journaling, nonce coordination and native OrderBook logic have passed scoped local regressions. They do not constitute a public exchange or real-value market.

No verified QZXB/USDT quote asset, reserve, bridge backing, liquidity pool, executable public order book, exchange pair, trade volume or public native price is established. The separate QX ERC-20 test asset on Ethereum Sepolia is not the native QZXB coin.

Production and Mainnet gates

  1. Attach the already-qualified operator and peer identity records to the exact release package and establish a stable, externally reachable Seed endpoint.
  2. Operate a distinct independently managed Joining node; verify pinned Noise identity, history transfer, reorganisation, restart and recovery against the candidate release.
  3. Complete reproducible release packaging and independent protocol, cryptography, economics and operational review, with documented remediation and a formal go/no-go decision.
  4. Complete and separately authorize any value-bearing Mainnet Genesis and its peer topology. The zero-value Testnet authorization cannot be reused for Mainnet.
  5. Only after an authorized native network exists, complete the public wallet/RPC/explorer and authentic market prerequisites before claiming balances, prices, liquidity or trading.

Transparency: published source code, a successful test suite, a built wallet executable and a signed zero-value Testnet authorization are different things from a launched public chain. No production Mainnet, public circulating QZXB balance, native QZXB market, listing or price is claimed.

Supporting engineering records and exact test scopes are maintained in the source repository. For contributions, independent node operation or security review, see the contributor guide.
