QRun Blockchain: Current Technical Status

This page separates what the source contains, what has local regression evidence, and what still needs independent proof before any production Mainnet decision.

Source branch and test-count boundaries

The public default main branch contains a curated source/documentation selection. The latest experimental source is on work/qzbe-v04-persistent-mining-20261026 (branch head recorded on 2026-10-29). Do not conflate its size and tests with the older curated public baseline.

Active branch inventory

1,187 listed test cases across 74 Cargo targets, including 931 in the main library target, from cargo test --all-targets --locked --offline -- --list. Listing tests is inventory, not a test-pass result.

Curated public baseline

The curated source commit c3a5474 recorded 735/735 library tests in the report dated 2026-10-21. That count belongs to that baseline, not the newer active branch.

Latest recorded run

The release-gate report records a successful local all-target test run on the active experimental worktree. A local pass is not an independent security audit, production-network soak test, or third-party reproducible-build attestation.

What blocks production Mainnet?

  1. Production consensus, Genesis and zero-mint supply rules must be frozen and enforced consistently across block production, import, replay, fork-choice and durable storage.
  2. At least three independent node/benchmark operators are required across separate hosts or providers. External inbound P2P and state-root convergence must be tested from separate networks.
  3. Full-history replay or a fully qualified checkpoint rollover with independent monotonic anti-rollback trust must be integrated end to end.
  4. Wallet signing/restore, transaction inclusion/confirmation, independent balance queries, a read-only public explorer/API, monitoring, reproducible release hashes and incident/reorg procedures remain to be qualified.
  5. An independent protocol/cryptography security review and remediation of critical/high findings are required.

Network safety and market status

The candidate listener configuration and host firewall rules do not prove router/NAT/ISP reachability. RPC and transaction ingress must remain loopback-only unless placed behind a separately hardened, authenticated and rate-limited gateway. Do not expose local administrative endpoints.

No public native QZXB price, live QZXB/USDT pool, verified market reserve or exchange listing is claimed. The separate QX contract on Ethereum Sepolia is a test asset, not native QZXB.

Primary evidence: repository audit, Mainnet/trading no-go, and 10B release gate.

Project status: QRun is experimental public-alpha, not production Mainnet. No public native QZXB market or price is claimed.
