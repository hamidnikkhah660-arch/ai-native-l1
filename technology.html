QRun Blockchain Technology: Rust Layer-1 Research

QRun is an open-source research and engineering effort around a native Layer-1 protocol. The codebase contains candidate implementations and tests; it is not a certified production network.

Native protocol and deterministic state

The public source tree covers Rust-based ledger research, deterministic transaction/state validation, candidate proof-of-work and difficulty adjustment, chain selection and reorganisation handling, state-root commitments, snapshot validation, persistence and archive-recovery experiments. These components are being integrated and qualified; the existence of a candidate module is not proof that every production node path uses it.

Protocol and consensus

Block validation, network/profile binding, fork-choice experiments, transaction checks and candidate supply invariants. A production consensus profile is not yet frozen.

Recovery and storage

Snapshot, archive replay, checkpoint codecs, rollback guards and crash-recovery tests. End-to-end full-history trust and independent anti-rollback operation remain release gates.

Authenticated networking

Peer identity pins, encrypted-session research, bounded wire parsing, worker queues and local multi-process synchronization tests. Internet-wide reachability and independent peer convergence have not been proven.

Wallet and developer tools

A Windows native-wallet CLI and signed-transaction candidates exist. A local Genesis account is not a public spendable balance; wallet interoperability requires chain-specific implementation and verification.

EVM and Solidity

The isolated EVM/revm lab and separate fixed-supply EVM test package cover contract execution, storage, gas, rollback, wallet-console and loopback-server behaviour. The package passed clean install, compilation, all local suites and a zero-finding npm audit on 2026-10-29; this is not proof of canonical EVM execution in the native QRun state machine.

AI-native applications

The roadmap includes agent identity, payments, verifiable job accounting and AI/compute coordination after concrete interfaces, measurements and operating rules exist. No production AI service is claimed.

Source and reproducibility

The public default main branch is a curated source/documentation baseline. The latest experimental source is maintained on a separate branch, work/qzbe-v04-persistent-mining-20261026. Review the exact commit, package manifest and test instructions before relying on a feature. The active branch is not a production release.

Next engineering milestones

  1. Freeze a single Genesis, network identity, consensus profile and monetary rule.
  2. Prove identical validation and recovery across block production, import, replay, forks and persistent storage.
  3. Synchronize independent nodes on separate networks and verify state-root convergence through restart and reorganisation.
  4. Obtain independent protocol and cryptography review and reproducible release evidence before a production decision.
Project status: QRun is experimental public-alpha, not production Mainnet. No public native QZXB market or price is claimed.
