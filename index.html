Open research · public source

Building a verifiable native Layer‑1, one test at a time.

AI-Native L1 is a research project exploring deterministic state transitions, authenticated peer transport, durable recovery, fixed-supply policy candidates, and post-quantum signature experiments. Source is openly available for worldwide technical review and collaboration.

Research status: this is not a production mainnet or an investment offering. No native mainnet launch, token sale, liquidity pool, exchange listing, live market price, revenue, or independent security audit is claimed here. The separate EVM candidate is a Sepolia testnet asset only.

What is in the source

Native research crate

Rust experiments for proof-of-work policy, transaction/state validation, authenticated networking, recovery, and reproducible test vectors.

Independent test fixtures

Cross-language vectors and mutation cases check encoding, monetary arithmetic, state commitments and fail-closed behavior.

Separate EVM candidate

A fixed-supply ERC-20 test asset with an isolated local-EVM suite; it is not the native L1 coin and is not approved for sale.
