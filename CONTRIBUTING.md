# Contributing

AI_NATIVE_L1 is a research prototype. Contributions should improve reproducibility, reviewability, safety, or a clearly demonstrated user workflow.

## Before opening an issue or pull request

- Read README.md, docs/PUBLIC_SOURCE_SCOPE_AND_RELEASE_STATUS_V01_2026-10-20.md, and docs/PUBLIC_RELEASE_MANIFEST_V01_2026-10-20.md.
- Keep research candidates and diagnostic-only paths clearly separated from canonical runtime, consensus, issuance and production key paths.
- Include reproducible test commands, expected outputs, failure cases, and the scope/limits of the evidence.
- Never submit wallet seeds, private keys, tokens, credentials, personal data, production logs containing secrets, or a real-value transaction.
- Do not represent the network or asset as production-ready, audited, listed, liquid, or an investment.

## License and provenance

Contributions intended for inclusion in project-owned source and documentation are submitted under Apache-2.0 by default, unless a different arrangement is agreed in writing with the project owner. By submitting a contribution, you confirm that you have the right to submit it under those terms. Preserve third-party notices and provide provenance/license information for copied or adapted content. Do not submit code, images, fonts, datasets or documentation whose rights you cannot establish.

The repository root LICENSE and LICENSES/README.md explain the project license scope and exceptions. The Qanvoryx brand assets are excluded from the default license.

No Contributor License Agreement is currently required. This does not waive the contributor's responsibility to own or have permission for their submission.

## Pull requests

- Keep changes scoped and focused.
- Add or update tests for behavior changes.
- Include a concise rationale, risks, verification steps and any release-gate implications.
- Do not mark a gate closed without evidence that its stated acceptance criteria were met.
- Do not introduce network listeners, cloud resources, paid services, production keys, token sales, or value-bearing deployments through a routine pull request.

All contributions remain subject to maintainers' review and the repository's security/release controls.
