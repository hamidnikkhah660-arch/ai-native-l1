Qanvoryx Wallet Console

Self-custody ERC-20 testnet interface · local static page

TESTNET ONLY
Not a mainnet wallet. This console only accepts Base Sepolia or Ethereum Sepolia and verifies the token bytecode against this repository’s compiled fixed-supply candidate. It is not the native AI_NATIVE_L1 coin. It never asks for a seed phrase or private key, and it stores no credentials. Do not send real funds or share secrets here.

1 · Connect a wallet extension

Not connected. Install/use a browser wallet extension and select a supported testnet.

Allowed chain IDs only: Base Sepolia (84532) and Ethereum Sepolia (11155111). Mainnets and local chains are refused.

2 · Deploy the fixed-supply candidate (testnet only)

Disabled until connected to Base Sepolia or Ethereum Sepolia. Your wallet extension must approve and sign the deployment transaction.

This creates a separate ERC-20, not the native L1 coin. All three allocations are immediately transferable with no vesting. The founder gets 40% only if the specified treasury address is the wallet you control. Deployment consumes testnet gas. No key or seed phrase is requested by this page.

3 · Enter the deployed testnet contract

A connected wallet address is not automatically the founder treasury address. Enter the treasury only if you independently control it. The console reads live on-chain balances and calculates the treasury's actual current share; it does not assume the wallet still owns 40% after transfers.

5 · Transfer tokens (testnet only)

Transfer disabled until wallet and exact contract bytecode are verified on a supported testnet.

The extension displays and signs each transaction; this page never has private-key access. Review chain, contract, recipient, amount, and wallet confirmation yourself. A transaction sent to the wrong address generally cannot be reversed.

Build fingerprint comes from the repository’s compiled contract runtime bytecode. Source-bytecode match does not replace an independent audit or prove RPC-provider honesty. No market pool, exchange, live price, or candlestick feed is connected. Testnet token balances have no promised monetary value.
